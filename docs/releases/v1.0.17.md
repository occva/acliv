# v1.0.17

## Changes

更新内容:

- 全面升级 Claude、Codex、Gemini、OpenClaw、OpenCode、Pi、OMP 与 DSH 会话解析，支持当前存储格式、Codex 压缩/归档会话及 SQLite 数据源。
- 完善 fork、分支、子代理、thinking、工具调用与错误、图片占位、模型和 token 等会话语义，减少重复历史与无效窗口。
- 加固搜索索引：纳入 SQLite WAL 更新，Provider 扫描失败时保留既有索引，并增加来源副本裁决与格式漂移诊断。
- 优化详情页消息导航和过程信息展示，使用左侧短标记、主题化预览，并改善连续切换与滚动恢复体验。
- 限制数据库托管会话的危险删除操作，避免直接破坏 OpenCode/OpenClaw 上游数据。
- 修复 macOS Dock 图标透明通道丢失导致的白色方框。
- 优化 CI、GitHub Actions 与 Docker 发布链路，复用缓存和主分支镜像，并让正式发布等待对应提交的 CI 门禁。
- 版本更新到 `1.0.17`。

Updates:

- Upgraded session parsing for Claude, Codex, Gemini, OpenClaw, OpenCode, Pi, OMP, and DSH, including current storage formats, compressed/archived Codex sessions, and SQLite-backed sources.
- Improved fork, branch, subagent, thinking, tool/error, image placeholder, model, and token semantics while reducing duplicated history and empty windows.
- Hardened search indexing with SQLite WAL tracking, preservation of existing rows on provider scan failures, source-copy arbitration, and format-drift diagnostics.
- Refined detail navigation and process rendering with compact left-side markers, theme-aware previews, smoother continuous toggling, and scroll restoration.
- Disabled unsafe deletion for database-managed sessions to avoid modifying OpenCode and OpenClaw upstream databases directly.
- Fixed the missing alpha channel that caused a white square around the macOS Dock icon.
- Optimized CI, GitHub Actions, and Docker release workflows with reusable caches and master images, plus a release gate that waits for CI on the tagged commit.
- Updated the app version to `1.0.17`.
