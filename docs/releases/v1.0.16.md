# v1.0.16

## Changes

更新内容:

- 新增 OMP 和 DSH 会话来源，支持会话扫描、消息解析、索引、删除与恢复入口。
- Web 和 Docker 部署新增 OMP、DSH 与 Pi 数据目录配置，容器环境可直接挂载对应会话目录。
- 优化 Provider 切换与索引界面：本机不可用来源收进“其他”，已索引来源筛选可正常显示并生效。
- 改进搜索索引弹窗布局，统一标题状态、等宽标签页，并精简会话卡片信息。
- 优化长目录侧栏滚动体验，使用透明轨道和按需显示的沉浸式滚动条。
- 完善 macOS 应用图标资源与显示比例，并新增无需 PowerShell 的原生检查、构建和发布脚本。
- 加固 DSH 会话删除路径校验，避免删除超出目标会话目录。
- 版本更新到 `1.0.16`。

Updates:

- Added OMP and DSH session providers with session discovery, message parsing, indexing, deletion, and resume actions.
- Added OMP, DSH, and Pi data-directory configuration for Web and Docker deployments.
- Improved provider switching and index views by grouping unavailable providers under “Other” and fixing indexed-provider filtering.
- Refined the search-index dialog with inline status, equal-width tabs, and cleaner indexed-session cards.
- Improved long sidebar navigation with transparent tracks and hover-only immersive scrollbars.
- Added native macOS ICNS resources and native check, build, and publish scripts that do not require PowerShell.
- Hardened DSH session deletion path validation to prevent deleting outside the target session directory.
- Updated the app version to `1.0.16`.
