# v1.0.18

## Changes

更新内容:

- 将 Codex Desktop 自动创建的 `Documents/Codex/YYYY-MM-DD/<任务>` 工作区统一归入 `Codex` 项目，同时保留真实工作目录用于恢复会话、复制路径和打开文件夹。
- 支持工作区目录已被清理的历史 Codex 会话继续正确归组，避免日期任务目录散落在项目列表中。
- 精简会话浏览布局：搜索入口移至项目侧栏，设置与主题操作收纳到 Provider 菜单，对话列表获得更完整的阅读空间。
- 将搜索排序和项目范围统一为下拉选择器，并完善 macOS 窗口拖拽区与菜单可访问性。
- 版本更新到 `1.0.18`。

Updates:

- Grouped Codex Desktop workspaces under `Documents/Codex/YYYY-MM-DD/<task>` into a single `Codex` project while preserving the real working directory for resume, path copy, and folder actions.
- Kept historical Codex sessions grouped correctly after their workspace directories have been removed, preventing date-based task folders from cluttering the project list.
- Simplified session browsing by moving search into the project sidebar, consolidating settings and theme actions in the Provider menu, and giving conversations more reading space.
- Standardized search sorting and project scope as dropdown selectors, and improved the macOS drag-region layout and menu accessibility.
- Updated the app version to `1.0.18`.
